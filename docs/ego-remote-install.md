# 집맥 ego Lite 설치

회사맥에서 공식 스킬의 설치 스크립트를 집맥으로 보내 실행한다.
집맥의 작업 세션에 설정 쓰기 권한을 더하지 않는다.
앱이 만드는 CLI와 스킬 링크는 설정 동기화에 넣지 않는다.
브라우저 프로필과 사이트 로그인도 맥마다 따로 둔다.

```sh
sh scripts/install-ego-remote.sh
```

SSH 대상은 `~/.config/herdr/remote-host`의 첫 줄이다.
다른 대상을 지정하려면 첫 인자로 SSH 호스트를 준다.
공식 설치 스크립트가 회사맥에 없으면 먼저 ego-browser 스킬을 설치한다.

설치 스크립트는 이미 설치한 앱을 다시 내려받지 않는다.
확인할 때는 SSH의 PATH에 기대지 않고 CLI의 절대 경로를 쓴다.
최초 설정 전에는 CLI가 종료 코드 0을 반환해도 JavaScript를 실행하지 않는다.
그래서 이 스크립트는 실제 출력이 없으면 종료 코드 3을 반환한다.
최초 설정은 앱의 공식 안내에 따라 사람이 마친다.
사이트 로그인이 필요한 작업은 별도로 인계한다.

최초 설정을 마치면 ego-browser 스킬 안내를 읽고 공개 페이지를 열어 확인한다.
`--version` 성공이나 앱 프로세스 존재만으로 페이지 제어 성공을 판정하지 않는다.

## 되돌리기

dotfiles 변경은 해당 커밋을 `git revert`한다.
앱 설치도 되돌리려면 ego Lite를 종료하고 `/Applications/ego lite.app`을 제거한다.
CLI·스킬 링크는 `readlink`로 ego가 만든 링크인지 확인한 뒤 해당 링크만 제거한다.
사용자 브라우저 프로필과 로그인 정보는 삭제하지 않는다.
전역 가드나 집맥 작업 세션의 sandbox는 변경하지 않으므로 복구할 설정이 없다.
