# 일반 세션 인계 검사 보강

## 목표와 범위

기존 인계 저장·Codex 시작 연결은 유지한다. 저장한 뒤 필수 항목이 손상되었거나
저장소 근거가 명시적으로 미검증인 경우 다음 세션에 검증 완료로 표시하지 않는다.
기존 자유 형식 메모는 경고와 함께 계속 읽는다. 메인 세션의 자동 저장 형식은 바꾸지 않는다.

## 구현 순서

1. 실제 임시 Git 저장소와 인계 명령으로 회귀 시험을 작성한다.
   - 읽을 때 빈 필수 항목·잘못된 형식이 경고를 내는지 확인한다.
   - 커밋이 같아도 근거가 `not verified`이면 경고하는지 확인한다.
   - 서로 다른 저장소의 브랜치·커밋·미커밋 상태 기록을 확인한다.
2. 실패를 확인한 뒤 저장과 읽기가 같은 필수 항목 검사를 사용하도록 수정한다.
   - 읽기 검사는 저장 당시의 스냅샷을 덮어쓰지 않는다.
   - 미검증 근거는 코드 일치 판정에서 제외한다.
3. 인계 상태·셸 통합·설치 시험과 저장소의 push 검사를 실행한다.
   - 기존 메모 읽기, 긴 메모, Codex 반복 시작·자식 세션 격리도 통과해야 한다.
4. 새 검토자가 전체 변경을 확인한 뒤 PR을 연다. 병합과 활성 설정 변경은 하지 않는다.

## 판단과 비용

명시적 미검증 표시는 문서가 안내하는 `not verified`를 기준으로 해석한다.
자유 문장의 진위를 자동 추론하지 않는다. 이 범위 밖의 근거 내용은 다음 세션이 읽고 판단한다.
형식 검사는 재사용하며 필드나 저장 형식 버전은 추가하지 않는다.

## 검증 기록

기존 시험: 상태 16개, 설치 2개, 셸 통합 시험 통과.
추가 시험의 실패·수정 후 결과 및 최종 검토는 PR에 기록한다.
