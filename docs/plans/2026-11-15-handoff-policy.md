# 로컬 인계 정책 검증

수신한 요청의 담당을 낡은 인계가 바꾸는 문제를 인계 저장 단계에서 막는다. 공개 저장소에는 특정 조직의 요청이나 기계별 담당 규칙을 넣지 않는다.

## 설계

- 선택: 선택적 로컬 JSON 정책의 정규식 규칙을 공용 인계 도구에서 검사한다. 개인 스킬의 설명만 바꾸는 방법은 이미 열린 세션의 낡은 기억을 막지 못한다. 공개 코드에 개인 담당 규칙을 고정하는 방법은 공개 범위를 넘는다.
- 정책 위치: `${XDG_CONFIG_HOME:-~/.config}/agent-hooks/handoff-policy.json`. 파일이 없으면 기존 동작을 유지한다. 잘못된 정책은 저장을 거절한다.
- 일반 세션과 메인 세션 모두 교체 전에 검사한다. 거절은 기존 인계를 보존한다.
- 이전 인계를 읽을 때 같은 정책을 검사하고, 위반 지시는 따르지 말라는 경고를 본문보다 먼저 넣는다. 원문과 남은 일은 보존한다.
- 기존 권한 검사와 안전 훅은 변경하지 않는다.

## 구현 순서

1. 저장 거절과 기존 파일 보존, 메인 자유 형식 인계, 손상된 정책을 실패하는 시험으로 먼저 고정한다. 이전 인계 읽기와 두 런타임의 시작 경로도 시험한다.
2. 정책 파서와 저장·읽기 연결을 구현한다.
3. 형식 문서에 로컬 정책 계약과 되돌리기를 적는다.
4. 인계 시험군과 셸 구문 검사를 실행하고 별도 검토를 받는다.

## 검증과 되돌리기

정책 거절은 저장 전이며 원자적 교체를 건드리지 않는다. 이미 저장된 위반 인계는 폐기하지 않는다. 정책 파일을 제거하면 정책 검사만 중단되며 기존 필수 인계 검증은 유지된다. 코드 되돌리기는 이 변경의 커밋을 revert한다.
