# 선택적 Stop 검사기 구현 계획

목표는 비공개 검사기로 메인 세션의 반응 처리를 확인하는 것이다.
worker와 정책이 없는 환경은 기존 동작을 유지한다.

공통 Stop 훅은 로컬 정책을 읽고 세션과 메인 terminal을 확인한다.
검사기에는 원래 payload를 stdin으로 전달하며 셸을 쓰지 않는다.
검사가 성공하면 차단하지 않는다.
검사기의 선택적 경고는 다음 입력에 전달한다.
잘못된 정책, 실행 실패, 시간 초과는 두 런타임의 Stop을 최대 세 번 차단한다.
그 뒤에는 5분간 재시도를 미루고 경고를 저장한다.
반응 규칙과 복구는 비공개 검사기가 맡는다.
기존 문장 검사와 inbox는 원래 순서대로 모두 실행한다.
반응 검사만 병렬로 수행해 기존 검사와 시간을 더하지 않는다.
검사기 제한은 최대 5초이며 전체 10초를 보장하지는 않는다.
기존 훅 등록과 신뢰 설정은 바꾸지 않는다.

1. 정책, 메인 신원, 실행 결과, 시간 제한과 두 런타임 payload를 먼저 실패 시험으로 확인한다.
2. 선택적 검사기를 구현하고 로컬 정책의 공통 형식을 문서에 적는다.
3. 회귀 시험과 격리 검사를 실행하고 독립 리뷰를 받는다.
4. 마지막 후보에서 일반 pre-push 검사를 완주한 뒤 PR을 낸다.

정책 연결을 지우면 이전 Stop 동작으로 돌아간다.
공개 코드 적용을 되돌릴 때는 별도의 리뷰된 변경으로 revert한다.
