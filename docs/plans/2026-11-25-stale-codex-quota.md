# 오래된 Codex 기록으로 대체 실행하기

## 목표와 범위

`claude-first`에서 Claude 예약분을 넘었을 때 Codex 기록의 나이만으로
자동 실행을 막지 않는다. 다른 정책과 로그인·유료 크레딧·API 설정 검사는 유지한다.

## 선택한 기준

전체 기록 유효기간을 늘리면 다른 정책까지 바뀐다. 대신 `claude-first`의
Codex 대체 실행에만 아래 조건을 모두 적용한다.

- 관측 후 10분 초과, 24시간 이하이며 현재 로그인 이후의 기록이다.
- 관측 당시 유효했던 주간 창이 아직 끝나지 않았다.
- 주간 사용량은 80% 이하다. 일반적인 새 기록의 95% 상한보다 15%p 낮다.
- 단기 창이 아직 열려 있으면 기존 80% 미만 제한을 지킨다.
  관측 당시 유효했지만 이미 끝난 단기 창은 판단에서 뺀다.
- 유료 크레딧 비활성화와 구독 로그인, API 환경·설정 검사를 통과한다.

24시간은 무기한 재사용을 막는 보수적 한계이고, 15%p는 그 사이 다른 세션에서
사용했을 가능성을 위한 추가 여유다. 최신 사용량을 보장하는 수치는 아니다.
같은 주간 창만 인정하므로 창이 끝났다고 사용량을 0으로 추정하지 않는다.
새 세션이 실행되면 새 관측치가 이후 결정을 대체한다.

## 실행 순서

1. 오래된 저사용량 기록의 자동 실행과 경계·안전 검사 회귀 시험을 먼저 실패시킨다.
2. 조건부 재사용, 두 공급자의 거절 사유, 확인 명령을 안내하는 거절 문구를 구현한다.
3. 스킬 관리 원본에 확인 절차를 넣고 이전 설치에서의 이행 시험을 추가한다.
4. 기존 quota·pane-spawn·스킬 설치 시험과 변경 검토 후 각 저장소 PR을 머지한다.

## 확인과 되돌리기

합성 기록으로 24시간·80% 경계, 만료 창, 단기 상한, 로그인 이전 기록,
유료 크레딧, API 환경·설정, 다른 정책의 기존 거절을 확인한다.
실제 계정으로 세션을 여는 시험은 하지 않는다. 되돌리기는 각 PR을 revert하고
스킬 설치 백업을 복원한다.
